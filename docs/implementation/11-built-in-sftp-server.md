# 11 内置 SFTP 服务器

## 实施目标

让 Feng Sync 可作为局域网轻量 SFTP 服务器，共享用户明确指定的目录。服务是程序级可选组件，可随程序启动并在托盘后台运行；若需要用户未登录时运行，则另行安装 Windows Service。

## 界面设计

“程序设置 → SFTP 服务器”分为四区：

1. **服务**：启用开关、随 Feng Sync 自动启动、监听地址、端口、最大连接、空闲超时。
2. **账号**：账号列表、启停、新建、编辑、删除；用户名、密码重置、SSH 公钥、只读/读写。
3. **共享目录**：每个账号配置虚拟名称、物理目录和权限，禁止目录重叠或越权。
4. **状态与安全**：启动/停止/重启、监听地址、在线会话、主机密钥指纹、防火墙状态、日志入口。

运行状态页提供 `sftp://IP:端口/`、复制按钮和二维码。首次启用向导依次完成监听范围、账号、共享目录、主机指纹确认和防火墙授权。默认端口建议 2222，默认只绑定局域网接口，不自动开放公网。

## 建议代码文件

- 初期在 `src/FengSync/SftpServer/` 下建立独立命名空间与目录；仅当服务端依赖冲突、Windows Service 或独立部署成为现实需求时再拆 `FengSync.SftpServer` 项目。
- 新增 `SftpServerHostedService.cs`：启动、停止、监听和优雅退出。
- 新增 `SftpServerOptions.cs`：非敏感服务配置。
- 新增 `SftpAccount.cs` 与 `SftpShare.cs`：账号、虚拟目录和权限模型。
- 新增 `SftpAuthenticationService.cs`：密码摘要、公钥认证、失败退避。
- 新增 `SftpVirtualFileSystem.cs`：路径解析、根目录隔离、文件操作。
- 新增 `SftpHostKeyStore.cs`：SSH 主机密钥生成、保护、指纹和轮换。
- 新增 `SftpAuditLog.cs`：登录与文件操作审计。
- 新增 `src/FengSync.Core/Execution/TransferLeaseManager.cs`：与同步器共享路径租约。
- 新增 `src/FengSync/Views/SftpServerSettingsControl.xaml` 与 `SftpAccountDialog.xaml`。
- 新增 `src/FengSync/ViewModels/SftpServerSettingsViewModel.cs`。
- 修改 `App.xaml.cs`：按设置管理 hosted service 生命周期。
- 修改扫描器：排除 SFTP 上传临时文件。

## 代码功能边界

- 桌面程序负责配置、状态和托盘生命周期；SFTP 项目只负责协议与文件访问。
- 密码保存强 KDF 盐化摘要或 DPAPI/Credential Manager 保护数据，界面永不回显原密码。
- 主机私钥独立保存并设置严格 ACL，普通配置文件只保存指纹和引用。
- 虚拟文件系统将所有客户端路径规范化后限制在共享根目录，防止 `..`、符号链接和 junction 逃逸。
- 上传先写 Feng Sync 专用临时文件，完成后原子重命名；中断上传不得被同步器当成完整文件。
- 只读权限在每个修改命令入口校验，不能只隐藏客户端按钮。
- 登录失败实施速率限制和临时封禁；限制总会话数、单用户会话数、带宽和文件大小。
- 防火墙规则创建与删除必须显式征得用户同意，并记录规则标识以便撤销。

## 运行流程

程序启动加载非敏感配置与密钥引用；仅在启用且自动启动时监听。客户端连接先协商现代 SSH 算法，再认证并建立用户虚拟根。写操作获取路径租约、写临时文件、刷新并提交，然后通知实时监控。程序退出时停止接受新连接，给予活动传输有限完成时间，随后安全取消并保留可清理临时文件。

若用户选择 Windows Service 模式，设置界面负责安装/卸载和传递机器级配置；桌面程序仅连接服务控制接口查看状态，避免同时启动第二个监听器。

## 异常与安全处理

- 端口占用、目录失效、密钥损坏、防火墙未放行分别显示可操作诊断。
- 未启用时不监听任何端口；“仅本机”模式必须拒绝其他设备。
- 不提供匿名、空密码、FTP 或自动路由器端口映射。
- 服务异常与主 UI、同步任务隔离；后台异常进入日志和状态页，不导致应用崩溃。
- 审计日志记录时间、账号、来源 IP、动作、虚拟路径、结果，不记录密码和文件内容。

## 验收标准

- 常见 Windows、手机、NAS 和命令行客户端能登录、列表、上传、下载、续传、重命名和删除。
- 重启后主机指纹稳定，自动运行配置生效，密码不可从磁盘恢复为明文。
- 只读账号以及路径穿越、大小写、符号链接、junction 测试均不能越权。
- 上传中断不会产生可见完整文件；同步与上传并发无半文件同步或死锁。
- 停止服务会优雅关闭会话，关闭功能后端口和由程序创建的防火墙规则可正确释放。
